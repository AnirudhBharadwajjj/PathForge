# PathForge - AI Career Navigator 🚀

A smart web platform that helps students and professionals discover their ideal careers using AI-powered assessments and real-time Indian job market insights.

![PathForge](https://img.shields.io/badge/version-1.0.0-blue.svg)
![React](https://img.shields.io/badge/React-18-61DAFB.svg)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue.svg)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.3-38B2AC.svg)

## 🌟 Features

### 1. **AI-Powered Smart Career Assessment**
- Intelligent personality and skills analysis
- Customized career matching algorithm
- Multi-dimensional profiling based on interests, skills, values, and work preferences

### 2. **Personalized Career Recommendations**
- AI-driven career matching with percentage scores
- Detailed career information including salary ranges in INR
- Growth trends specific to the Indian job market
- Required education and skills for each career path

### 3. **Skill Gap Analysis**
- Identifies missing skills for desired career paths
- Recommends relevant courses and certifications
- Provides learning resources from top platforms
- Tracks skill development progress

### 4. **Career Roadmap Visualization**
- Clear visual timeline from education to expert level
- Step-by-step milestones for career progression
- Interactive roadmap with detailed phase information
- Customized paths based on Indian education system

### 5. **Real-time Job Market Insights**
- Current salary trends in Indian Rupees (₹)
- Job demand by major Indian cities (Bangalore, Hyderabad, Pune, etc.)
- Industry growth rates in India
- Top skills in demand

## 🎨 Design

- **iOS 16 Inspired Design**: Clean, modern interface with glassmorphism effects
- **Responsive Layout**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Animations**: Powered by Framer Motion for delightful user experience
- **Accessible**: Built with accessibility best practices

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS 3.3 with custom iOS-inspired design system
- **Animations**: Framer Motion
- **Charts**: Recharts for data visualization
- **Icons**: Lucide React
- **AI Logic**: Custom AI matching algorithms for career recommendations

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/pathforge.git
cd pathforge
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🚀 Available Scripts

- `npm start` - Runs the app in development mode
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
- `npm run eject` - Ejects from Create React App (one-way operation)

## 🎯 Key Features Explained

### AI Career Matching Algorithm
The platform uses a sophisticated AI algorithm that:
- Analyzes user responses across multiple dimensions
- Weights responses based on importance
- Considers Indian job market demand
- Provides match percentages with reasoning

### Indian Market Focus
- All salaries displayed in Indian Rupees (₹)
- Focuses on major Indian tech hubs
- Considers Indian education system (B.Tech, M.Tech, etc.)
- Tracks growth in Indian industries
